# PLAYFy Home Screen launcher

This creates a removable Home Screen Web Clip that opens **LiveContainer → Husk → your PLAYFy import**. It is not an Apple App Store App Clip or an independent native PLAYFy app. No extra sideload slot is used; existing JIT requirements still apply.

## Browser generator

1. In PLAYFy's settings inside Husk, use **Generate App Clip**. Save/export its generated profile.
2. In LiveContainer, long-press Husk and use its Home Screen/App Clip profile option. Save/export that profile too. The **Copy Launch URL** option can be used instead for this input.
3. Open [the generator](https://0RageQuit.github.io/Husk-Video-PiP/), select both files, and create your launcher. If you already have their launch URLs, paste those instead.
4. Open the generated profile on your iPhone and approve installation in Settings. Replace an older launcher profile if needed.

Both inputs stay in the browser. The generated profile uses the app's own icon when supplied, the correct import/container IDs and **FullScreen=true**. The corrected fullscreen profile was reported working on the test phone; an earlier non-fullscreen profile opened Brave instead.

You can download `index.html` and use it offline. The browser tool accepts unsigned XML profiles generated by the apps; use the Python tool for binary plists. CMS-signed profiles are not supported.

## Python generator

Requires Python 3, no extra packages:

    python shortcuts/make_launcher.py --husk-profile PLAYFy.mobileconfig --livecontainer-profile Husk.mobileconfig --output PLAYFy-Launcher.mobileconfig

Use the profile generated for the **Husk guest** in LiveContainer, not a different app. This tool preserves the launch scheme and any container selection from that profile.

## Read the IDs from your USB-connected phone

If exporting profiles is awkward, the optional read-only USB helper can generate the launcher from your existing app folders. It reads labels, icon and launch metadata only; it does not import or install an app/profile or copy APKs.

    python -m pip install -r shortcuts/requirements-usb.txt
    python shortcuts/from_phone.py --output PLAYFy-Launcher.mobileconfig

Unlock and trust the computer first. If multiple LiveContainer apps or PLAYFy imports are found, the helper asks you to choose with a command-line option rather than guessing.

## Using the icon

Tap it to start your existing Husk import. If another Android app is running inside Husk, close that guest first; Husk cannot load another translation engine in the same run. Reimporting PLAYFy or moving it to another data container may require generating the shortcut again.

The profile contains only a removable Web Clip. It does not enroll the phone in management, change the default browser or install certificates. To remove it, remove its profile in Settings.
